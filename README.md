# Web profesional de Fran Gonzas

**Sitio oficial:** https://frangonzas.github.io/

Sitio estático de presentación profesional dedicado al desarrollo de software, la ingeniería de sistemas, la seguridad defensiva y la radiofrecuencia.

## Contenido

- Presentación y áreas de especialización.
- Portfolio de proyectos públicos y vínculos a sus repositorios.
- Tecnologías principales y principios de ingeniería.
- Páginas de soporte y políticas de privacidad.
- Sitio específico de **Kolechat** en la ruta \`/kolechat/\`.

## Publicación

GitHub Pages sirve la rama \`main\` como web estática. La estructura no requiere un servidor de aplicaciones.
